肆响应式：共享状态 · 列表 · 条件

诗句存在一个 store（模块里的 signal）中，下面的列表和这一行计数是两个组件，读取同一份数据。 列表用 repeat 按 id 复用节点：点“打乱”时，只有真正被移动的行会重新晕开一次，其余 DOM 原地不动。 

// stores/poems.js
export const poems = signal([...]);
export const visible = computed(() =>
  onlyFavorites.value ? poems.value.filter((p) => p.favorite) : poems.value);

// 组件模板
${repeat(visible, (p) => p.id, (p) => html`<li>${p.text}</li>`)}
